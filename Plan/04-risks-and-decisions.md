## 需要管理的風險

| 風險 | 影響與最早處理時點 | 處理方式／責任 |
|---|---|---|
| 通道排序與衰落假設不一致 | W01；獨立衰落可能使近區低於遠區 | 代理提出保持已定近／遠排序的模型候選，由您決定；不宣稱此限制是實測定律 |
| 0 附近的有效距離未定 | W01；部分傳播模型在極近距離不適用 | 先定模型有效距離及不合法配置的處理，不偷偷裁切成任意值 |
| SNR 與干擾語意不清 | W01；若把干擾放進分母，通常是在表示 SINR | 設計時分清接收功率、噪聲與干擾；保留可讀名稱和單位，由您確認模型含義 |
| PHY／EH 正式參數不足 | W01／W04／W05，影響研究有效性 | 代理先查既有規範索引及原文；缺資料時呈現缺口，fixture 是否先行由您選擇 |
| 空服務／輪末收尾未定 | W02／W08，影響停止及最後事件 | 先列有限情境與預期值再實作，不以舊多週期描述代答 |
| 共用 dataclass 檔不一致 | W02 及各模組新增欄位 | 保留單一入口，增加欄位時核對使用端；不建立多份 Config 真值 |
| 人工導讀疲勞或無法排入 | 所有 H；是交付關卡 | 每日 2 h 容量上限、短段落、保留問題；未接受不抽離 |
| 同時事件與能量因果返工 | W08／W10，跨模組風險 | 小情境先驗、事件順序置換、單一狀態提交及相同區間不重算 |
| Baseline 尚有排序／公平性缺口 | W11；不能直接將手稿當正式演算法 | 對照原方案、反例與候選規則；由您確認，不暗中更換研究方法 |
| 研究來源或算力不足 | W12／W13；有限工期無法保證補齊外部證據 | 預先定實驗矩陣與資源上限，缺證據保持待驗證；另估外部工作 |
| 合併等待拖長順序交付 | 每包 M | 額外 1／2 日已列敏感度；不自動合併或跳過授權 |
| CLM 重訓或多輪需求 | M2 之後可能擴大範圍 | 另建工作分解及估算，不吸收進現有 20% 準備 |

## 開始 W01 前的第一個模型決策

每日 2 h 的參與容量已確認，不重問。接下來建議只先討論**參數與驗收依據的順序**，其他通道細節在選定方向後逐項處理。

例如：要驗證「同一 Window 不重抽 SNR」，用明標的簡單測試參數就能檢查；但要聲稱「50 m 戶外可可靠回傳」，還需要符合場景的模型與參數依據。兩者的驗收目標不同。

| 選項 | 執行方式 | 對排程的影響 |
|---|---|---|
| **A：雙層驗收（建議）** | 先用您同意的明標 synthetic 情境驗證程式與排序；正式模型來源逐項補齊，在 M3 前做可信度驗收 | 容易維持 M1 的小步交付；不能拿測試情境作正式研究結果 |
| B：正式參數優先 | 先確認適用於場景的通道與實體參數，足夠後才進原型 | 減少早期替換，但資料取得時間可能使 W01 超過本版估算 |
