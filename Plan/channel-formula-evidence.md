# 通道公式選型：共址背散射與有限碼長

日期：2026-10-25。狀態：**文獻核對及設計建議，公式組合尚待討論接受**。本次沒有實作 Channel 或執行 PHY／RF 模擬。

- 使用者已選 A：先以明標測試參數驗證程式，正式模型與參數逐項查證、替換並複驗。
- 新要求：公式要容易說明；TBS 是小資料量，必須考慮**有限碼長（finite blocklength）**。
- 已確認調變／接收器：固定 BPSK＋相干接收，接收端相位資訊可用列為研究假設；尚未選定實際編碼配置或接收器BLER曲線。
- 已確認窗級變動：同Node各Tag共用窗級增益因子。同一DU Window內SNR不變。下一DU Window更新該因子。各窗獨立抽樣。
- 2026-10-29已確認初版測試幅度為±3 dB。偏移採 `delta_jw ~ Uniform(-3 dB, +3 dB)`。此值供測試使用，尚未經戶外校準。
- 沿用：CW／Reader 共址、平面靜態拓樸、同窗品質固定、同 Node／同 Window 近區優於遠區、自身殘餘 CW 自干擾 0 W。

## 1. 建議的衡量鏈

```text
位置／距離、CW功率、Tag反射參數
    → 去程與回程的接收訊號功率
    → 加入噪聲／外部干擾，得到接收品質
    → 對應到解調器的每次通道使用SNR
    → 配合資訊bit數k、碼長n，估計整包錯誤率ε
    → PHY按此機率決定本次接收結果
```

- Channel 提供當窗通道與接收功率；Access／PHY 根據固定格式決定碼長、時間及接收結果。
- ServiceManager 只認列成功收到的有效新 payload；TBS、CRC 及重複傳送不是三份新資料。
- 「600 ms DU Window」是可排程時間，不是每個封包都傳 600 ms，也不是有限碼長 n。

## 3. 第一段：訊號要走去程和回程

用功率增益來寫，符號比較容易與單位對應：

\[
P_{\mathrm{rx},k,w}
=P_{\mathrm{CW},j,w}\,\beta\,g_{j\to k,w}\,g_{k\to j,w}.
\]

| 符號 | 意義／單位 |
|---|---|
| j／k／w | 所屬Node／Tag／DU Window |
| P_CW | 該Node的CW發射功率，W；功率設定可由Donor指定 |
| beta | 有效反射／調變功率係數，無因次；不是振幅係數，也不直接等同所有未採能功率 |
| g_f／g_b | 單程功率增益，無因次；天線／損失的包含範圍需固定，避免重複計入 |
| P_rx | Node收到的目標D2R訊號功率，W |

在同頻互易、相同方向幾何的研究近似下，兩段功率增益相同，故 `P_rx=P_CW beta g²`。這對應IEEE原文 `|h|⁴`，因為功率增益 `g=|h|²`。

為了保留可讀的距離關係，可選單程參考距離模型：

\[
\bar g(d)=g_0\left(\frac d{d_0}\right)^{-\eta},\qquad
P_{\mathrm{rx}}=P_{\mathrm{CW}}\beta g_0^2\left(\frac d{d_0}\right)^{-2\eta}.
\]

- eta 是**單程**路損指數，必須正值；g0／d0 是參考增益／距離，不在本次填任意正式值。
- 距離加倍，回傳目標功率變成 `2^(-2 eta)`；若僅作算術例取 eta=2，便是1/16，約減12.04 dB。這不是已選農場參數。
- 不能再把同一雙程損失重乘一次；也不能用單程NR接收功率直接充當背散射回傳功率。
- 模型需要有效最小距離；拓樸排除d=0不代表任何接近0的距離都適合此近似。[Needs Verification：有效範圍與校準]

### 接收品質

\[
N=N_0B_{\mathrm{eq}}F,\qquad
\gamma_{\mathrm{SNR}}=P_{\mathrm{rx}}/N,\qquad
\gamma_{\mathrm{SINR}}=P_{\mathrm{rx}}/(N+I_{\mathrm{ext}}).
\]

- 先用線性W相加，最後才轉dB；N0為熱噪聲密度W/Hz、B_eq為等效接收帶寬Hz、F為線性noise factor。
- 殘餘自身CW干擾已設0 W，外部干擾I_ext尚未定，不能一併刪掉。
- 將外部干擾當高斯等效噪聲後套AWGN公式是研究近似；有強結構化／非高斯干擾時須另驗證。
- RF功率比須轉成解調／通道使用的SNR，不能只因都叫SNR就直接代入。若複數符號率Rs、等效噪聲密度N_eff，則 `Es/N_eff=P_rx/(Rs N_eff)`；只有相應帶寬／符號率約定成立時，才等於上式功率比。實數BPSK還要對齊每實數維的噪聲變異，避免差3 dB。

### 外部干擾如何表示（2026-10-29，已選A）

- 自身CW的殘餘干擾維持0 W。
- 外部干擾仍是獨立的設定項。
- SNR只比較目標訊號與噪聲。
- SINR也把外部干擾列入分母。
- 若要計入干擾，解碼模型使用SINR。
- 兩種比值仍需對齊符號與噪聲單位。

| 候選 | 表示方式 | 代價與限制 |
|---|---|---|
| A：固定等效功率（建議首版） | 每Node明列接收端外部干擾功率。該值在一輪內固定。值由測試配置提供。 | 易解釋及核對。未逐一模擬干擾來源。 |
| B：逐一模擬干擾來源 | 列出來源、發射時段及傳播增益。接收器加總當時的干擾功率。 | 可描述來源及時間變化。需要額外參數與時序。 |

- A的功率指接收端的有效帶內功率。
- 固定干擾不等於沒有干擾。
- A若套AWGN有限碼長式，需採等效高斯干擾假設。
- 使用者已選A，採上述等效干擾的研究近似。
- 每Node的I_ext在一輪內固定。
- 各Node可明列不同值，實際數值尚待確認。
- 本題不指定正式的干擾數值。
- B若包含UE，還需提供額外的傳播依據。
- 既有UE只有邏輯歸屬，沒有實體座標。

### Tag反射能力（2026-10-29，已選A）

- beta表示有效反射功率係數。
- 相同距離下，beta會影響接收功率。
- beta不同時，共同窗級因子不足以保證近遠排序。
- 候選A：所有Tag使用相同beta，值由Config提供。
- 候選B：Tag可有不同beta，另定保持近遠排序的約束。
- A較容易控制比較條件，建議首版採用。
- 此選擇不自動決定EH效率或電池容量。
- 本輪不填定正式beta值。
- 使用者已選所有Tag共用同一beta。
- beta為固定配置，不隨Window重新抽樣。
- 此決定取代本節的候選待答狀態。

### 如何滿足已定的近區優於遠區

- 同Node、同Window若beta、發射功率、接收噪聲／干擾與其他乘數相同，上述單調距離模型自然保持排序。
- 若每個Tag獨立抽Rayleigh衰落或任意反射係數，仍可能反轉；不能只說平均近區較好就宣稱符合需求。
- 使用者已選同Node共同窗級正乘數，保留距離排序；不另外抽Tag獨立衰落。這是本實驗的研究限制，不冒稱IEEE原文普遍假設。
- 同窗保留通道狀態；同窗的更新次數為一次初始化。下一窗需產生品質變化；不能僅因重新呼叫亂數就認定實際輸出已不同。尚未要求所有非相鄰歷史窗口的數值永不重複。
- 更新後仍檢查近區優於遠區；不將CW開關或能量更新誤當成重抽通道的時點。CW未開啟時沒有實際D2R訊號，當窗SNR快照表示在該窗指定CW條件下的D2R品質。
- 使用者已選跨窗獨立抽樣，不以在上一窗數值上加減的random walk產生新因子；中區是否也須嚴格排序仍待討論。窗邊界識別用Window ID，不以「又過600 ms」推定新窗已出現。
- 已選dB偏移的有界均勻分布。若其作用在整條反射鏈路的功率增益，線性共同因子為 `A_jw=10^(delta_jw/10)`；不能在去程與回程各乘一次A而把偏移加倍。在互易雙程模型中，單程功率增益對應乘sqrt(A)；後續EH應依單程入射功率核對，不能直接把雙程偏移完整加到採能功率。
- 獨立抽樣與「相鄰窗實際SNR數值不同」分開檢查。連續非退化分布下相等是零機率事件；有限精度仍需檢查，不能為強迫不同而任意加減數字，暗中改變所選分布。精度／生成失敗的處置需在實作驗收列明。

## 4. 第二段：有限碼長決定整包錯誤率

對已選通道／輸入分布，其normal approximation可寫為：

\[
R^*(n,\epsilon)\approx C(\gamma)
-\sqrt{\frac{V(\gamma)}n}\,Q^{-1}(\epsilon),\qquad R=k/n.
\]

反過來，給定資訊量與實際碼長，名義錯誤率模型為：

\[
\epsilon_{\mathrm{NA}}(\gamma,k,n)
\approx Q\!\left(\frac{nC(\gamma)-k}{\sqrt{nV(\gamma)}}\right).
\]

- k：該次編碼訊息的資訊bit數；n：傳送該碼字的通道使用次數，**不是TBS bit數**。
- C：每次通道使用能承載的容量，bit/use；V：資訊量波動的尺度，bit²/use。
- Q：標準常態分布右尾機率；結果epsilon表示整包錯誤率BLER，不是單一bit錯誤率BER。
- 更長的碼通常允許更多冗餘；只說TBS很小，還不足以決定n。固定SNR時，n和k一起決定負載與可靠度。
- 上式省略高階項，是理想碼效能的近似；不是保證上／下界，也不是所選卷積碼的實測曲線。極短碼、極低錯誤率、無編碼傳送需另核對。

### 易解釋的高斯參考版

若一個use定為一個**複數**AWGN符號、採理想高斯輸入，則：

\[
C(\gamma)=\log_2(1+\gamma),\qquad
V(\gamma)=\left[1-(1+\gamma)^{-2}\right](\log_2 e)^2.
\]

- 這是研究參考版本；實數AWGN的C及V各有相應1/2因子，不能混用。
- 以k=128 bit、gamma=1（0 dB）作純教學例，n=160時epsilon約0.0214；n=192時約0.000109。這比較不同冗餘，不是已採用的標準TBS／碼率配置。
- OOK／BPSK屬有限星座，C／V要依實際輸入及接收器選定，不能無條件用上面的高斯輸入式；例如二元輸入每次二元使用的容量不會無限隨SNR增加。
- 若選相干BPSK，可用作者教材的bi-AWGN資訊密度平均／變異來得到C／V；一般Q式仍相同，內部可數值算表，導讀不必一開始推完整積分。若選OOK或非相干接收，改用相應模型，不硬套BPSK結果。

## 5. 規範中的TBS如何接到k／n／時間

TS38.291 §6.1.2中，令A為L1收到的D2R transport block長度：

- CRC長度L：A>24 bit時16 bit，否則6 bit；CRC後長度 `B=A+L`。
- 區塊重複後 `B_R=R_block B`。
- 若省略通道編碼，輸出長度 `E=B_R`；若使用§8.2碼，輸出 `E=3 B_R`，該碼為constraint length7、rate1/3 tail-biting convolutional code。
- 隨後插入preamble／midamble，再依OOK或BPSK及SFS映射到chips；傳送時間須以完整格式計算。

| 概念 | 需要的處理 |
|---|---|
| 服務新payload | 去除非應用資料；成功與去重後才認列 |
| A／TBS | 包含上層交給PHY的TB；與本專案MAC header的對應需封閉 |
| k | 代表被編碼訊息集合的資訊量；CRC由資訊決定，不是新增獨立資訊。簡化令k=A也需明示可變header等假設 |
| n | 依實際編碼、調變及接收器模型決定的通道使用次數；不能直接設成A、E或含ambles的全部chips而不說明模型 |
| SFS／重複 | 影響能量、時間及冗餘；不能既把合併增益加進SNR，又把相同重複當理想新碼字資源，重複計好處 |
| 固定碼率 | 若實際碼率固定，選不同TBS時k與n會一起變；教學中的「固定k只變n」不是任意允許改碼率 |
| 總批次時間 | Paging／offset、D2R的ambles與資料、Guard分開；FBL資料碼長不等於總批次時間 |

因此建議介面保留 `snr/sinr`、正規化約定、`tb_bits`、`information_bits`、`coded_bits`、`data_channel_uses`、`duration_ns`、`phy_model_id`；名稱是候選，不是已實作DTO。

## 6. 本輪建議及驗收限制

1. **通道骨架**：共址的去程×回程增益＋明示噪聲／干擾，從單調距離模型開始討論。
2. **短封包骨架**：使用依賴gamma、k、n的整包錯誤率；保留匹配調變的C／V，避免只有Shannon容量門檻。
3. **第一版A流程**：可用高斯normal approximation作明標參考／程式測試；正式研究必須表明是否採理想有限碼長抽象，或替換成符合固定PHY的短碼BLER表。
4. **校驗**：需要在實際TBS／SNR範圍用非漸近界或獨立鏈路模擬檢查近似；對特定規範碼的BLER則以其接收器／解碼器曲線驗證。兩者不互相取代。
5. **解碼事件**：每個實際封包完成只產生一次接收結果；同窗多包可各自有結果，但不重抽整個通道。批次隨機獨立性及錯誤相關性要明示。
6. **同步／偵測**：FBL資料碼字模型未自動包含amble偵測失敗、估測誤差或CRC漏檢；若先假設理想同步／錯誤偵測，必須列為研究假設。

使用者已選固定BPSK＋相干接收。C／V須匹配二元輸入。高斯輸入式僅留作參考。

各Tag共用所屬Node的窗級因子。同窗固定，跨窗獨立更新。偏移採有界均勻分布。2026-10-29已選±3 dB為測試幅度。

以下項目仍待確認：有效距離、頻段／參考增益、CW功率、帶寬／符號率、外部干擾、Tag反射參數及目標錯誤率。未確認的值不作正式參數。

## 7. 距離模型的解析度（已選A）

- 所有Tag共用beta的決定已確認。
- 接下來決定區內距離是否影響品質。
- 例：兩個Tag距離為5 m及9 m。
- 兩者都在近區，但距離不同。

| 候選 | 基礎品質如何決定 | 取捨 |
|---|---|---|
| A：使用實際距離（建議） | 採單程參考距離增益，再計去回程。指數、參考值及有效距離列Config。 | 能表達區內差異。需要明示參數來源。 |
| B：依三區查表 | 每區設定一個基礎接收品質。區內Tag共用該值，再加窗級偏移。 | 參數較少。區內距離不再影響品質。 |

- A的候選式為g(d)=g0(d/d0)^(-eta)。
- 共址互易模型再使用g(d)的平方。
- 該骨架沿用前述背散射文獻。
- 此題不預先選定eta、g0或d0數值。
- B是較粗的分區研究抽象。
- 兩者均須滿足既定近遠排序。

### 2026-10-29低功率補充（待釐清）

- 使用者已選實際距離模型。
- 使用者要求低power時，品質差距不要太大。
- 使用者另說「不會調包」。
- 需先確認該詞指排序還是封包遺失。
- 不預設已選定SNR或BLER的差距門檻。

同Node兩個Tag的比較條件一致時：

\[
\frac{\gamma(d_1)}{\gamma(d_2)}
=\left(\frac{d_2}{d_1}\right)^{2\eta}.
\]

- 此處假設正CW功率、共同beta及噪聲／干擾。
- 兩者也共用窗級因子。
- CW功率在比值中相消。
- 降低共同功率不會縮小dB差距。
- 理想公式的排序仍由距離決定。
- 若指避免掉包，還需指定BLER目標。
- 也需給定最低功率、碼長及服務資料量。
- 不保證任意低功率下都能可靠接收。

### 已釐清：要求以掉包機率表示

- 「調包」指接收失敗，不是排序交換。
- 使用者要低CW時，近區不掉包。
- 中區有一定機率掉包。
- 遠區必定掉包。
- 此描述取代先前的含糊差距要求。

| 區域 | 低CW下的期望接收行為 |
|---|---|
| 近區 | 掉包機率0 |
| 中區 | 掉包機率介於0與1 |
| 遠區 | 掉包機率1 |

以上是模型要求，尚未驗證參數可滿足。

### 早期SINR分段骨架（已由功率表優先取代）

\[
p_{\mathrm{fail}}(\gamma,k,n)=
\begin{cases}
1,&\gamma\le\gamma_{\mathrm{fail}}(k,n),\\
\epsilon_{\mathrm{FBL}}(\gamma,k,n),
&\gamma_{\mathrm{fail}}(k,n)<\gamma<\gamma_{\mathrm{reliable}}(k,n),\\
0,&\gamma\ge\gamma_{\mathrm{reliable}}(k,n).
\end{cases}
\]

- gamma是對齊接收器定義後的品質。
- 兩個門檻須依k與n明確設定。
- 0／1兩段是額外研究假設。
- 中間段保留有限碼長的影響。
- 此式不是3GPP規定的BLER曲線。
- 若只用有限碼長近似，則保留接近0／1的值。
- 兩種作法的零失敗及必失敗語意不同。
- 此骨架曾獲接受。
- 後續第33.14節已改採功率表優先。
- 不再以本式決定所有封包的最終接收類別。

提高CW後，接收功率會上升。
Tag可能因此跨過相應門檻。
不必改變Tag的幾何分區。

若要各幾何區嚴格滿足表格，需驗證整區邊界。
驗證也要包含±3dB、TBS及碼長範圍。
共同偏移可能讓門檻距離移動。
不能只依TagZone名稱宣稱結果成立。

### 三區行為的驗收範圍（待確認）

- 近／中／遠區是固定的距離分區。
- 可靠／隨機／必失敗是接收狀態。
- 接收狀態由當窗品質及門檻決定。
- 共同±3dB偏移會移動門檻的距離位置。
- 同區Tag仍可能在不同窗進入不同接收狀態。

| 候選驗收範圍 | 意義 |
|---|---|
| A：基準窗對齊（建議） | 在低CW、偏移0及明列TBS／碼長配置下，校準三區行為。其他窗仍按品質與門檻判斷。 |
| B：每窗都保證 | 低CW下，每個Window都要近區成功、中區隨機、遠區失敗。需驗證整個偏移與TBS／碼長範圍。 |

- A的基準窗是校準案例，不是新增必有的隨機窗。
- B若無法滿足，需回頭調整模型。
- 不會因選B就默默覆寫接收品質。
- 不預設固定門檻可滿足所有幾何部署。

例如，9.9m與10.1m分屬近區和中區。
連續距離模型的基礎品質可能很接近。
若近區在最差偏移仍要可靠，中區在較佳偏移也可能可靠。
這會影響「所有中區每窗都只能隨機成功」的要求。
因此，兩種驗收範圍需要分開確認。

### 已確認：中區可靠接收需中等CW

- 使用者有條件選擇基準校準A。
- 中區要進入可靠接收，CW須升至中等功率。
- 單靠±3dB偏移，不可觸發該轉換。
- 前述只靠偏移就可靠的例子已被取代。
- 同窗SNR固定，窗級因子仍跨窗獨立。
- 下一窗功率由系統配置指定。
- 不推定固定的低→中→高輪替。
- Policy仍只選Tag及TBS。

| 情境 | 中區的接收狀態 |
|---|---|
| 低CW，窗級偏移改變 | 不能只因偏移而變成可靠接收 |
| 下一窗設定中等CW | 可依目標配置進入可靠接收 |

- 這是待驗證的模型要求。
- 功率檔位、固定門檻與隨機幅度需一起核對。
- 近／中區交界的連續增益也需核對。
- 不保證任意參數能滿足全部要求。
- 若只靠SINR門檻不可行，需明示修改方案。
- 不會默默增加功率檔位閘門或修改SNR。

使用者已確認中等CW的遠區目標。
遠區有成功機會，但仍可能掉包。
實際機率及功率數值仍待設定。
