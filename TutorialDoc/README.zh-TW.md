# 教學單元

這些單元說明目前的拓撲與通道模組。
請先透過[專案快速開始](../README.zh-TW.md#快速開始)準備環境並執行範例。

1. [架構與資料流](architecture.zh-TW.md)：模組如何連接，以及結果的使用限制。
2. [IAB 拓撲](unit/iab-topology.zh-TW.md)：拓撲設定與輸入限制。
3. [通道模型](unit/channel-model.zh-TW.md)：鏈路公式、研究規則與封包接收。
4. [資源時間表](unit/resource-timeline.zh-TW.md)：已接受的 UE／Tag 區間核心位於 src/timeline，並提供可執行 Notebook。

各模組指南提供更多設定與操作細節。
能量、接入、排程與完整模擬時間軸尚未整合。
