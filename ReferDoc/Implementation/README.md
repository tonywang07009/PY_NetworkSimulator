## 說明書會涵蓋什麼？

每個功能的說明都依操作順序安排：

1. 能做什麼，以及適用的場景。
2. 開始前需要準備什麼。
3. 可以調整的設定與具體例子。
4. 操作步驟與標準流程圖。
5. 表格、圖片與輸出檔案怎麼看。
6. 常見問題與處理方式。
7. 目前的使用範圍與相關文件。

每個功能使用獨立資料夾，中英文各有總覽、設定、操作、結果與常見問題，方便分段閱讀。先前合併草稿保留供比對。

設定背後的研究決策見 [Plan](../Plan/)；標準原文見 [Spec](../Spec/)。程式與開發檢查紀錄另由 [IAB 程式目錄](../../src/iab/) 提供。

## 撰寫與圖表方式

本專案沿用使用者提供的清晰寫作原則。

- 句子要短，中文每句盡量不超過30字。
- 一句只說明一件事。
- 同一概念使用同一個詞。
- 使用主動語態，清楚指出主詞。
- 術語首次出現時，先用白話說明。
- 公式先說用途，再列符號及單位。
- 公式後提供簡短的計算例子。
- 文獻引用保留章節、式號及來源。
- 分清文獻結論、研究假設與測試設定。
- 短句不得刪除必要條件或限制。

流程圖採標準符號，由上往下閱讀。

| 內容 | 畫法 |
|---|---|
| 開始／結束 | 橢圓或圓角起訖符號 |
| 處理 | 矩形 |
| 判斷 | 菱形；分支標示「是／否」 |
| 輸入／輸出 | 平行四邊形 |

- 節點寫「虛擬碼行號＋一句功能說明」。
- 例如：「3. 系統計算接收功率」。
- 行號必須對應實際提供的虛擬碼。
- 未提供虛擬碼時，不編造行號。
- 有參考圖片時，再對齊視覺樣式。
