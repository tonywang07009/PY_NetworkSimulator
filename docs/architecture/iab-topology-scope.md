## 原圖與規範已核對的證據

- **main.pdf**：[原檔](../../ReferDoc/Plan/main.pdf)，11 頁，完整抽文字；第 3、4 頁已渲染檢視。第 3 頁為農場、非均勻部署、參考 TR 38.901；第 4 頁標示 Distance／SNR zones，並註記 SNR 也受通道影響。圖中 2 Nodes／各 1 UE 是示意，節點數依使用者新配置為 5 Nodes／5 UE。圖沒有實際長度尺度或 SNR／干擾數值，不能從像素直接換算公尺。
- **split 邊界**：由索引導向 [TS 38.300 V19.4.0](../../ReferDoc/Spec/IAB/TS_138_300_v19.4.0.pdf) §16.23.2，核到該版本 A-IoT 不支援 split gNB。外部官方副本：[ETSI V19.4.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.04.00_60/ts_138300v190400p.pdf)。本研究整合 Reader 仍清楚標成擴充，不把假設變成標準事實。
- **D1T1 與共址**：[TR 38.769 V19.0.0](../../ReferDoc/Spec/A_IoT/TR38769.pdf) §3.1 定義 D1T1 是 Deployment scenario 1＋Topology 1；Table 4.2.1-1 的 D1T1-A2 描述 CW 與 R 在同一節點。D1T1 本身不是 Device type 1 或共址的同義詞；也不能僅因共址就默認採用該表全部頻段／裝置／功率設定。
- **環境差異**：[TR 38.848 V18.0.0](../../ReferDoc/Spec/A_IoT/TR38848.pdf) §4.2.2.1 的 D1 是裝置／基地台皆室內；§4.2.1.1 描述 T1 直接通訊。IAB 整合屬研究擴充，不能只因圖上有 IAB 回傳就自動改成另一種 A-IoT 拓撲分類；需明示把本地整合 Reader 當作直連接收端的研究映射。

這是指定本地版次的核對，不聲稱已核驗所有較新版規範或全部 IAB／A-IoT 協定功能。TR 是研究背景，不能取代規範性 TS。

- Config／DTO／必要 Enum 定義最後集中單一共用 `.py`；內部 State 留各模組。當前先在 Notebook 原型，不先建立最終 `.py`。
- 上述為研究模型及使用者選擇，不宣稱拓撲或任意無線連線自動符合 3GPP。適用的規範要查 `ReferDoc/Spec/spec_index.json` 再核原文；本輪未做規範符合性核驗。

## 建議的首版模組責任

**輸入**：經確認的節點、座標／部署參數、連線／歸屬設定及必要 Seed。

**處理**：建立節點及有種類的連線，檢查 ID 與參照有效性、父子回傳及接入歸屬，計算所選維度的幾何距離。

**輸出**：可重現的拓撲資料、節點／連線摘要、部署圖與對應情境斷言結果。實際距離不等於可成功通訊，配置連線也不等於 BER／吞吐已驗證。

此責任範圍是建議，尚未完成使用者範圍確認。若需求只要空間節點或還需動態移動，依後續答案調整，避免提前實作完整網路模擬器。

## 情境測試候選

| 情境 | 對應檢查 |

| 合法 Donor／Node／UE／Tag 場景 | 1 Donor、5 Nodes、5 UE；5 條直接回傳關係、各 Node 的 UE 歸屬；Tag 依設定關聯，不漏配或重複配；Node 整合 Reader 的表示一致 |

## 距離分區與近區優於遠區已定（2026-10-23）

Node 完美消除自身CW殘餘自干擾已定；該理想化模型不納入自身CW造成的前端飽和／去敏，但其他Node／UE外部干擾是否存在仍待定，CW傳播與採能仍保留。

Q-DESCRIPTION-05 已回答 A：距離影響實際接收SNR；同一PHY設定與目標錯誤率使用相同成功門檻，不額外提高遠區門檻。尚未指定傳播模型或SNR值。

Q-DESCRIPTION-06已回答A並補充：按所屬Node距離定近／中／遠區，10／13／7對應全場幾何配額例子；近區SNR須優於遠區，是使用者指定的system model約束，取代允許品質反轉的先前草案。先以同Node／同Window比較，不自行推為不同Node功率下的全域排序；中區嚴格排序與差距尚未明定。後續Channel生成需保留此約束，不能僅以平均較好取代。

Q-TRADEOFFS-03已回答A：五個Node共用可配置的三區外邊界10／30／50 m；相對所屬Node，0<d<=10為近區、10<d<=30為中區、30<d<=50為遠區（單位m）。d=0排除，Channel有效最小距離仍待定。這是部署幾何，不是已驗證覆蓋距離。
