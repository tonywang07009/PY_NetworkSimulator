## 已實作規則

先用剛結束區段的 phase 更新電量，再處理邊界。只有 UE UL／DL 可採能，UE 結束後保留 1 ms 切頻。
操作開始前檢查完整成本；操作中的快照只顯示目前時刻電量，不提前套用最終電量。
同時 D2R 先批次收集，再更新資源與處理新請求。Deadline 保持嚴格小於。
同一 Tag 的同時衝突請求整組拒絕；不同 Tag 可獨立推進。
跨窗口、空檔與分段 run 都保留電量；恢復狀態不會自動啟動。
