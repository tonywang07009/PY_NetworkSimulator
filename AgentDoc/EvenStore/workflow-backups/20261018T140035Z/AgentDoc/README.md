# Agent 工作文件

開始：`openspec/PROGRESS.md` → `openspec/HANDOFF.md` → 指定 change。

| 文件 | 用途 |
|---|---|
| [PROJECT_BOOTSTRAP.md](PROJECT_BOOTSTRAP.md) | 可重用的前置流程與重建命令 |
| [tool-inventory.json](tool-inventory.json) | 工具形式、版本與驗證界線 |
| [openspec/](openspec/) | 任務、規範、進度與交接 |
| [EvoSkill/README.md](EvoSkill/README.md) | 技能原始定義、Wiki 與改善路徑 |
| [EvenStore/](EvenStore/) | 搬移與工具驗證的原始證據 |

`EvenStore` 沿用現有名稱。既有 `.gitignore` 忽略 AgentDoc 與 ReferDoc；需要跨機攜帶時須另外備份，或由使用者決定版本控管策略。
